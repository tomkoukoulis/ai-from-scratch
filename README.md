# Build Your First AI From Scratch
*(No Libraries)*

Understand how AI actually works before using TensorFlow, PyTorch, or LLM APIs.

* **Target Audience**: Experienced developers
* **Prerequisites**: Basic algebra
* **Language**: Python 3.11+
* **Dependencies**: None (Standard Library only)

---

## Project Roadmap

| Folder | Topic | Description | Time | Status |
| :--- | :--- | :--- | :--- | :---: |
| `01-linear-regression/` | Linear Regression | Predict house prices from size using MSE and Gradient Descent | 1–2 hours | 🛠 In Progress |
| `02-logistic-regression/` | Logistic Regression | Binary classification using probabilities, Sigmoid, and Cross-Entropy Loss | 2–3 hours | ⏳ Planned |
| `03-neural-network/` | Neural Network | Forward propagation, backpropagation, and solving the XOR problem | One evening | ⏳ Planned |
| `04-mnist-framework/` | Deep Learning | Implement models using deep learning frameworks on the MNIST dataset | One weekend | ⏳ Planned |
